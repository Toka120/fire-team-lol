FIRE LoL

L'application de l'équipe.
Les stats se consultent uniquement dans l'application, avec le code d'équipe.

⬇ Télécharger FIRE LoL pour Windows Version portable (sans installation)
  1. Lance le fichier téléchargé. Si Windows affiche « Windows a protégé votre ordinateur », clique sur Informations complémentaires puis Exécuter quand même.
  2. Au premier lancement, entre le code donné par le coach.
  3. C'est tout : les stats, les fiches du coach et les nouveautés se mettent à jour à chaque ouverture, et l'application installe toute seule ses nouvelles versions.
