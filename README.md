# Apps du FIRE Launcher (versions d'origine)
FIRE Kiting et FIRE Listen tels que livrés. Remplacer un .exe ici (même nom) puis envoyer : GitHub reconstruit
l'application avec le menu admin (workflow apps-build.yml sur main), la publie dans la release « apps »,
et FIRE Launcher installe la nouvelle version chez toute l'équipe.
